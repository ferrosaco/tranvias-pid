# Which transit agencies are supported?

Este fork solo muestra los buses de A Coruña. Los datos salen de la API de iTranvías de la Compañía de Tranvías de La Coruña, no de un feed GTFS.

El panel pide las llegadas directamente a iTranvías. Para elegir la parada, el configurador usa [https://configurador-coru.vercel.app](https://configurador-coru.vercel.app), descrito en [API Server](../../03-advanced/api-server.md).

## Otra ciudad

Este repositorio no añade otras redes. Para otra ciudad hace falta el proyecto original y su API, que sí acepta GTFS y otras fuentes.
